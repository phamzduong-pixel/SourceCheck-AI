# Metrics

Định nghĩa và triển khai các hàm tính toán chỉ số đánh giá:
- Chỉ số Retrieval: MRR@K, NDCG@K, Recall@K, Precision@K.
- Chỉ số Verification & Classification: Accuracy, Macro/Micro F1, Precision, Recall.
- Chỉ số Generation & Factuality: Faithfulness, Answer Relevance, Citation Precision / Citation Recall.
